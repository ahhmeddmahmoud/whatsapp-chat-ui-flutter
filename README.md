# 💬 WhatsApp Chat UI — Flutter

A WhatsApp-inspired chat interface built with Flutter and Dart, focused on clean widget architecture, responsive layouts, and reusable UI components.

> **Note:** This is a front-end UI implementation only. There is no backend, real-time messaging, or authentication — the goal of this project was to practice recreating a polished, production-style interface using Flutter widgets.

## ✨ Key Features

- **Custom App Bar** — Replicates WhatsApp's header with user info and action icons
- **Chat Message Bubbles** — Styled sent/received message bubbles with proper alignment
- **Image Messages** — Support for displaying image content within the chat
- **Input Bar** — Text input field with a voice message icon, matching the original design
- **Reusable Widgets** — UI broken into modular, reusable components for maintainability
- **Custom Header Bar** — Chat-specific top bar showing contact name and call icons

## 🚀 Getting Started

Clone the repository and run it locally:

```bash
git clone https://github.com/ahhmeddmahmoud/whatsapp-chat-ui-flutter.git
cd whatsapp-chat-ui-flutter
flutter pub get
flutter run
```
